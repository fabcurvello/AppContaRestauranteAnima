# App Conta de Restaurante (Anima)

> Repositório didático: exercício prático de Android nativo com **Java**, desenvolvido e aplicado em sala de aula pelo Prof. Fabricio Curvello.

## Sobre o projeto

Aplicativo que recebe o valor da conta de um restaurante e calcula o total com **10% de taxa de serviço**.

## Contexto acadêmico

Exercício aplicado em sala de aula em turma de desenvolvimento mobile do grupo **Ânima Educação**. A Ânima Educação é um conglomerado de instituições de ensino superior brasileiras, do qual fazem parte o Centro Universitário IBMR (Rio de Janeiro) e a UNA (Minas Gerais).

## O que o app faz

- O usuário digita o valor da conta.
- Ao tocar em **Calcular**, o app soma 10% e mostra o total formatado em reais (`R$ 0,00`).

## Conceitos trabalhados em aula

- Entrada de dados numéricos com `EditText`
- Conversão de `String` para `double`
- Formatação de valores com `String.format`
- Tratamento de clique com `setOnClickListener`

## Tecnologias

- **Java**
- **Android SDK** (Android Studio)
- **Gradle**
- `minSdk 29` / `compileSdk 35`

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/fabcurvello/AppContaRestauranteAnima.git
   ```
2. Abra a pasta no **Android Studio** e aguarde a sincronização do Gradle.
3. Execute em um emulador ou dispositivo físico com Android compatível com a API 29 ou superior.
